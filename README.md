# Castle Battle

[在浏览器中试玩 · Play in your browser](https://escapingbug.github.io/castlefight-web/)

The browser build includes Castle Fight’s 15-wave single-player survival mode, Ashfall Survivors, and Wayfarer’s Trials (行旅试炼), with offline friend challenges and text save codes.
